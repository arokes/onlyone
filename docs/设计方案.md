## 2. 四条硬约束

1. **企微在线文档只读链接**：官方限制应用只能读写自己创建的文档，成员创建的文档无 API 可读 → 只存标题 + URL + 归属项目，点击用默认浏览器打开；可选手动导出本地副本纳入索引。
2. **爱数走客户端同步盘**：AnyShare Windows 客户端「同步盘 → 设置 → 本地同步/自动下载」把有权限的目录落地为本机文件夹，程序把它当普通本地目录索引。权限由客户端继承，程序不越权、不接触企业令牌；权限回收的文件在下次扫描时移出索引。OpenAPI 列二期（需企业接口文档与授权）。
3. **凭据不进全文索引**：FTS 索引明文可检索，含密码文档不得纳入；凭据单独加密存储，且从索引数据源中排除。
4. **Office 只读**：内嵌编辑器不会优于本机 Office/WPS，且自研编辑器回写会破坏原文件 → 只抽取正文做预览和检索。

## 3. 免主口令的凭据方案（Windows DPAPI）

用户要求「不需要主口令，直接查看，仅本机本人」。采用 Windows DPAPI：

- `CryptProtectData` / `CryptUnprotectData`（`ctypes` 调 `crypt32.dll`，**零额外依赖**），默认绑定**当前 Windows 用户账户**；可选附带熵与描述串 `OnlyOne`。
- 每条字段单独加密成 BLOB 存 `credentials` 表；程序启动即可解密，无解锁步骤、无口令输入、无找回问题。
- **实测通过**（2026-11-06）：加密 25 字节明文得到 184 字节密文，解密往返一致。

安全边界（必须知悉）：

| 能做到 | 做不到 |
|---|---|
| 数据库文件被拷走后，在**别的 Windows 账户 / 别的机器**上打不开 | 阻止同一 Windows 账户下运行的**其他程序**调用 DPAPI 解密 |
| 避免明文落盘、避免密码进 FTS/日志/导出 | 抵御已登录本账户的恶意进程或管理员 |

→ 即「防文件外泄」，不是「防本机已登录攻击者」。凭据页**账号常显**（M8 起，使用需求：一眼看清是哪个账号），密码 / 链接 / 备注仍默认掩码、逐条点击显示，复制后 30 秒清剪贴板。

## 4. 旧格式 `.doc/.xls/.ppt` 兜底（本机实测）

实测：`soffice` / `libreoffice` / Microsoft Office 均**未安装**，PATH 上也无 `antiword` / `catdoc`；**已安装 WPS Office 10.8.2.6837**（`C:\Program Files (x86)\Kingsoft\WPS Office\10.8.2.6837\office6\wps.exe`），DPAPI 亦可用。

三级策略：

| 级别 | 做法 | 依赖 |
|---|---|---|
| 1 | `.xls` 用 `xlrd==2.0.1` 直接读单元格 | 纯 Python，最稳 |
| 2 | `.doc/.ppt` 经 WPS COM 自动化（`pywin32`）另存为 `.docx/.pptx` 到临时目录 → 复用标准抽取器 → 删临时文件 | `pywin32`；需 M2 用真实文件验证 WPS 的 ProgID 是否可用 |
| 3 | 转换失败 → 标记 `extract_error`，**仍索引文件名**，在「索引目录 → 失败清单」中可见并提示手动另存 | 无 |

新格式抽取：`.docx`(python-docx)、`.xlsx`(openpyxl read_only)、`.pptx`(python-pptx)、纯文本(charset-normalizer)，另加 `.pdf`(pypdf)。加密/损坏文档一律走级别 3。

**M2 实测补充（2026-11-06，WPS COM 15 个 ProgID 全部可用）**：Writer 另存 `.docx` 必须用 `FileFormat=12`（`wdFormatXMLDocument`）；`FileFormat=16` 会「调用成功但产物仍是 OLE2 的 `.doc`」，python-docx 打不开。PPT 另存 `.pptx` 用 `24`，WPS 表格生成 `.xls` 用 `56`。不传 FileFormat 时 WPS 按原格式保存、无视扩展名，因此**每次转换后必须校验产物前 4 字节为 `PK\x03\x04`**。备用路径：`Document.ExportAsFixedFormat(pdf, 17)` 导出 PDF，pypdf 可正确读出中文。COM 在 FastAPI 线程池中需 `pythoncom.CoInitialize()` 并用全局锁串行化。

## 7. 索引与中文检索

- 扫描：`size + mtime` 快速判定 → 变更才算 `sha256`；排除 `~$*`、`.git`、`node_modules`、`data/`、索引库自身、>50MB 文件（仅索引名）。
- **中文实测**：Python 3.14.7 / SQLite 3.50.4 的 FTS5 `trigram` 对**两字中文词失效**（`MATCH '灾备'`、`'数据'` 返回 0；`'灾备恢复'`、`'数据库'` 返回 1）。→ 主用 trigram，查询词少于 3 字符自动降级 `LIKE` 扫描。
- 增量：`watchdog` 监听 + 启动时全量校准；抽取失败进重试队列，超过 3 次列入失败清单。
- 每次扫描写日志：扫描文件数 / 新增 / 更新 / 删除 / 失败 / 耗时。
- **扫描执行（M8）**：默认走后台任务（`POST /api/roots/{id}/scan?wait=false`），前端轮询 `GET /api/scan/status` 显示「已完成 / 总数 · 百分比 · 当前文件 · 预计剩余」。`wait=true`（默认）保留同步语义，供回归脚本沿用旧契约。
- **写锁（M8）**：每 50 个文件或 2 秒提交一次，把写锁从「整轮扫描」压缩到秒级；`connect(timeout=30)` 让偶发争用自动重试。修复前一次全量扫描会把锁占满全程，期间新增项目 / 凭据 / 笔记一律在 10 秒后 500（`database is locked`，已实测复现）。
- **系统目录（M8）**：`SKIP_DIRS` 常驻排除 `$RECYCLE.BIN`、`System Volume Information`、`Windows`、`Program Files*`、`ProgramData`、`AppData`、`Recovery` 等，目录名大小写不敏感。此前把 `D:\` 登记为根时会扫进回收站与系统目录。
- **pptx 表格（M8）**：python-pptx 1.0.2 的 `_CellCollection` 不支持切片，`row.cells[:40]` 会抛 `TypeError: '<' not supported between 'slice' and 'int'`（含表格的 pptx 全部抽取失败）。改为 `list(row.cells)[:40]`。

### 8.3 布局与组件

- **左侧一级导航 208px**：品牌区（OnlyOne + 副标题）→ 三组（知识 / 业务 / 系统）→ 底部「本地运行 · 无云端依赖」与版本号。当前项用浅橙底 + 左侧 2px 橙色竖条 + 橙色文字；图标为 24×24 线性 SVG（无图标库依赖）。
- 页签顺序：全局搜索、记事本 ｜ 项目事项、工作日志、运维记录、企微链接 ｜ 凭据库、索引目录。垂直排布不再需要溢出下拉（原 `NavTabs.vue` 已删除，由 `SideNav.vue` 取代）。
- **全局搜索**：`Ctrl+K` 聚焦；结果按类型分组，标题为「眉标 + 类型名 + 计数胶囊」；命中片段用 `<mark>` 标出查询词（先转义再包裹，防 XSS）；顶部一行统计（字面 / 语义 / 外部 + 检索方式标签）。
- **只读预览**：正文与表格放在 `--paper-2` 色块内，与卡片形成层次；仍无编辑、无保存。
- **索引目录**：页面顶部四格统计条（索引目录 / 索引文件 / 全库条目 / 抽取失败），停用的根目录显示「已停用」标签。
- **凭据页**：直接查看（无解锁），默认掩码、逐条显示、复制后 30 秒清剪贴板。
- **首次启动向导**：设置索引根目录、爱数同步盘目录。
