### 2.6 M6 能力边界（保留）

1. OCR 是**离线模板匹配**（Pillow + 系统中文字体 + numpy），非通用神经 OCR；适用清晰印刷体。原因：Python 3.14 无 onnxruntime/torch 轮子，Windows 内置 WinRT OCR 的异步桥接被环境安全策略拦截，按规则未绕过。检测到 tesseract 自动优先。
2. 扫描 PDF 用 pypdf 取 `page.images` 字节流走 OCR，无需渲染库；纯矢量扫描件仍标失败。
3. 语义检索是**本地确定性稀疏向量**（11 组同义词 + 字符 n-gram + 余弦），非神经嵌入；替换 `semantic.embed()` 可升级。
4. 三组结果独立分组、不混排。

### 2.9 M7 能力边界与风险（重要）

1. **笔记进 FTS 是明文索引**（FTS5 表无加密），`data/onlyone.db` 被拷走即读到全部公开笔记；同一 Windows 账户下的其他进程也可读。FTS5 删行不擦页、WAL 保留历史版本，自动保存越频繁磁盘明文残留越多 —— 已用「2 万字截断入索引 + 保存后 `wal_checkpoint(TRUNCATE)`」缓解，但**未消除**。用户已明确接受此本地场景风险。
2. **私密页开关**是护栏：`is_private=1` 不建 `entries` 行，因此不进 FTS / 语义 / 全局搜索；但仍以明文存 `notes.content_json`，不是加密存储。
3. **凭据导出只做 C**：导出文件只含密文，口令丢失不可恢复；不做 A（DPAPI 密文原样，换机不可恢复）与 B（明文，违反 §10）。全库备份会包含凭据 DPAPI 密文，同样**换机不可直接解密**，跨机请用凭据加密导出。
4. **图片附件**落 `data/attachments/`，不进 FTS；导出时重写为 zip 内相对路径，导出文件不含一次性令牌。附件读取路径对令牌放行（本地随机端口 + 其余 API 仍受保护）。
5. **TipTap 富文本**的 `content_json` 由前端生成，后端只抽文本与做导出白名单渲染（转义 + 仅允许本地附件路径），不执行任何 HTML；编辑器本身不 `v-html`。
6. **导出文件名用 ASCII**（HTTP 头只能 latin-1），中文标题保留在导出内容里 —— 本轮修过一次 500。
7. 富文本目前支持粗体/斜体/标题/列表/代码块/图片；**未做**自由画布定位、手写墨迹、页面双向链接、云端同步（与单机离线约束冲突）。

### 2.15 M8 扫描体验与缺陷修复（2026-11-06 本轮）

用户报三个问题：凭据账号要常显、创建项目报错、扫描报错。实测定位到**四个独立缺陷**（"扫描报错"实际由两个叠加造成）：

| # | 现象 / 根因 | 证据 | 修复 |
|---|---|---|---|
| M8-1 | 凭据列表把所有加密字段都返回掩码 | `credentials.py::_public()` 对 `ENC_FIELDS` 一律 `••••••••` | 账号单独解密明文返回（解密失败给空串），密码/链接/备注保持掩码；前端账号列去掉「显示/隐藏」只留「复制」，编辑弹窗回填账号 |
| M8-2 | 创建项目 500 | 实测 `HTTP=500 TIME=10.145`，`database is locked` | 扫描由「整批单事务」改为**每 50 文件或 2 秒提交**；`connect(timeout)` 10 → 30。实测扫描 403 文件期间连发 8 次写请求全部 200，单次最长 0.04s |

**回归事故与根治**：`verify_notes.py` 的凭据测试是「导出全库 → 删一条 → merge 导入 → 断言 imported==1」。库里一旦有用户自己的凭据，这条断言必失败，且每次运行都把用户凭据再复制一份（实测 3 条被复制成 21 条，已清理回 3 条）。现改为**独立数据目录**（`ONLYONE_DATA_DIR` 指向临时目录，在 `import onlyone.db` 之前设置），跑完 `shutil.rmtree`。**后续任何会写凭据的回归脚本都应照此隔离。**

## 5. 关键技术事实（别重复踩坑）

1. **FTS5 trigram 对两字中文词失效**：必须保留 trigram + 短词/零命中 LIKE 兜底。
2. **DPAPI 的 `c_byte` 有符号**：`db.py` 已改 `c_ubyte`；安全边界是防文件外泄，不防同账户其他进程。
3. **WPS COM 格式常量**：Writer `.docx`=12（不是 16）、PPT `.pptx`=24、ET `.xls`=56；另存后校验 `PK\x03\x04`。
4. **统一条目写入责任**：业务表 / 文件 / 笔记任何写入都要调 `entries.sync_entry`（或 `notes._sync_note_entry`）；删除走对应 `drop_entry`。笔记的 `entries` 无外键，裸 SQL 删除 notebooks 前必须手动清 `entries` / `fts_entries` / `semantic_index`（`purge()` 已处理）。
5. **扫描串行化**：`scanner._SCAN_LOCK` + `wps_session()`（`threading.local()`）。
6. **打包路径**：`db._base_dir()` 在 frozen 时取 `sys.executable.parent`；`data/` 与 `frontend/dist/` 必须在 EXE 同级。
7. **回归脚本不可并发**：七个脚本共用 `data/onlyone.db`，必须串行。
8. **`npm --prefix` 在 Git Bash 不生效**：必须 `cd frontend && npm install`。
9. **Vue 模板坑**：`v-for` + 长 `v-else-if` 链会让 `vue-tsc` 报错 → 拆子组件；`NSelect` options 需显式 `SelectOption[]`。
10. **HTTP 头只能 latin-1**：`Content-Disposition` 文件名必须 ASCII，中文放内容里。
11. **本用户工程约定**：含中文路径下不要落地 `.ps1`/`.bat` 再执行；改代码 / 改配置 / 改文件前**先给方案、等明确确认再动手**；中文、结论先行、表格化、最小改动、便于回滚。
