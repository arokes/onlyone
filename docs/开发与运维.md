## 运行

开发期两个进程：

```powershell
cd D:\WorkBuddy\onlyone\backend
py -3 run.py --no-window --port 8765

cd D:\WorkBuddy\onlyone\frontend
npm install
npm run dev
```

生产形态（单进程窗口，自动启用文件监听）：

```powershell
cd D:\WorkBuddy\onlyone\frontend
npm run build
cd ..\backend
py -3 run.py
```

`run.py` 随机选空闲端口、生成一次性令牌（仅本进程有效），前端从 URL 取令牌后放进 `X-OnlyOne-Token` 请求头。API 只监听 `127.0.0.1`。桌面窗口创建失败时自动降级到系统默认浏览器，也可手动加 `--browser`。

技术栈：FastAPI + pywebview + Vue 3 + Naive UI，架构对齐 ACMNG，代码独立编写。

## 打包（文件夹交付）

```powershell
cd D:\WorkBuddy\onlyone
py -3 build.py
```

产物在 `dist\OnlyOne\`（**111.2 MB**）：`OnlyOne.exe` 与 `frontend\dist\`、`data\` 同级。**整个文件夹一起拷走**即可离线运行，不是单 EXE。

`OnlyOne.exe` 用 `--noconsole` 打包（PE Subsystem=2），**启动不弹命令行窗口**；代价是没有控制台输出，所有异常写 `data\onlyone.log`（`run.py` 已做 `sys.stdout is None` 兜底，并把 uvicorn 自带日志配置关掉）。需要另存产物目录时用 `py -3 build.py --dist-dir dist_next`，可保留旧产物不被覆盖。

### 前端热更

只改了 `frontend/` 时无需重打 PyInstaller，重建前端后镜像覆盖即可：

```powershell
cd D:\WorkBuddy\onlyone\frontend
npm run build
robocopy "D:\WorkBuddy\onlyone\frontend\dist" "D:\WorkBuddy\onlyone\dist\OnlyOne\frontend\dist" /MIR /NFL /NDL /NJH /NJS
```

`/MIR` 会顺带清掉旧 hash 产物。改后端 Python 必须重新打包。

### 版本号与升级

唯一真值是 `backend/onlyone/__init__.py` 的 `__version__`，侧栏底部与窗口标题都取这一处，EXE「属性 → 详细信息」由打包时生成的版本资源写入。

| 命令 | 效果 |
|---|---|
| `py -3 build.py` | **不升级**，按当前版本打包（默认） |
| `py -3 build.py --bump patch` | `0.1.0 → 0.1.1`（`minor` → `0.2.0`，`major` → `1.0.0`） |
| `py -3 build.py --set-version 0.3.2` | 直接指定版本（与 `--bump` 互斥） |

升级会同步改写 `backend/onlyone/__init__.py` 与 `frontend/package.json`，并生成 `build/version_info.txt`。

## 索引库体积维护

`fts_entries` 是 FTS5 trigram 索引：条目更新都是 `DELETE` + `INSERT`，死段与空闲页不会自动归还。实测 1367 条条目时库文件 309 MB，其中有效数据只有 108 MB。维护手段有两级：

| 方式 | 触发 | 效果 |
|---|---|---|
| 自动 | 每次扫描任务结束后，空闲页 ≥16 MB 且距上次 ≥1 小时 | 后台线程做 `optimize` + `VACUUM`，实测 109.8→108.9 MB，约 4 秒 |
| 手动 | `py -3 tools/db_maintenance.py`（**先退出 OnlyOne**） | `optimize` + `VACUUM`，实测 309.1→108.1 MB（回收 65%），6 秒 |

阈值可用环境变量覆盖：`ONLYONE_COMPACT_MIN_FREE_PAGES`（默认 4000 页 = 16 MB）、`ONLYONE_COMPACT_MIN_INTERVAL_SEC`（默认 3600 秒；`0` 表示每次扫描后都做）。`--no-vacuum` 只合并索引段不动磁盘；`--dry-run` 只打印指标。压缩前后检索结果与条目数不变（`integrity_check` + FTS `integrity-check` 已校验）。

## 环境变量

| 变量 | 作用 |
|---|---|
| `ONLYONE_TOKEN` | 固定访问令牌（脚本与回归用；不设则随机生成） |
| `ONLYONE_DATA_DIR` | 覆盖数据目录（回归用独立临时库） |
| `ONLYONE_COMPACT_MIN_FREE_PAGES` / `ONLYONE_COMPACT_MIN_INTERVAL_SEC` | 索引压缩阈值与间隔 |
| `ONLYONE_KENSAKU_CLI` | 指向真实外部 CLI 时才启用外部索引后端 |
| `ONLYONE_HOTKEY` | 覆盖捕获热键，如 `ctrl+alt+k` |
| `ONLYONE_HOTKEY_OFF` | 设为 `1` 关闭全局热键 |

## 回归

下列脚本各自拉起后端，无需手动启动服务；**必须串行运行，不要并发**（共用同一个 SQLite 库）。

```powershell
cd D:\WorkBuddy\onlyone
py -3 tools\smoke_test.py     # M1：状态 / 根目录 / 扫描 / 中文检索 / DPAPI
py -3 tools\verify_m2.py      # M2：真实 Office 文件端到端，约 30–60s（含 WPS COM）
py -3 tools\verify_m3.py      # M3：业务记录 / 关联 / 跨类型检索
py -3 tools\verify_m4.py      # M4：凭据 / 明文泄漏 / 敏感排除
py -3 tools\verify_m5.py      # M5：watcher / 失败队列 / 重建 / EXE 离线启动
py -3 tools\verify_m6.py      # M6：OCR / 语义相近 / 外部索引插件
py -3 tools\verify_notes.py   # M7：三级笔记 / 自动保存 / 图片 / 表格导出 / 凭据加密恢复
node tools\verify_note_table_ui.mjs   # 记事本表格界面：插入 / 合并 / 自动保存（CDP，需先 npm run build）
node tools\verify_note_import_ui.mjs  # 记事本导入界面：文件 / 文件夹选择 → 分区落库（CDP，自包含样本）
node tools\verify_note_layout.mjs     # 记事本布局：顶部页签固定 / 左右独立滚动 /「更多」收纳（CDP）
node tools\verify_note_restore.mjs    # 记事本状态恢复：切页签回原分区页面 + 卸载前补保存（CDP）
node tools\verify_incident_filters.mjs # 运维记录筛选：全文 / 时间区间 / 公司 / 状态 / 项目（CDP）
py -3 tools\import_mht_notes.py --input <某个.mht>   # OneNote 迁移试跑（不加 --write 不落库）
py -3 tools\verify_m8.py      # M8：后台扫描进度 / 并发写 / pptx 表格 / 系统目录排除
py -3 tools\verify_incidents_rich.py    # 运维记录富文本：JSON 存取 / 图片池 / FTS 取纯文本 / 老数据兼容
py -3 tools\capture_incident_ui.py      # 运维记录列表渲染（Chrome headless + DOM 断言）
py -3 tools\capture_incident_editor.py  # 搜索跳转 + 双击行开编辑 + 弹窗编辑器 + 模拟 Ctrl+V 贴图（CDP）
py -3 tools\verify_overview.py          # 概览接口：计数 / 最近改动 / 超期判定 / 参数夹取 / 空库降级
py -3 tools\capture_overview_ui.py      # 概览页渲染：默认落地 / 四个区块 / 超期标记（Chrome headless）
py -3 tools\verify_features.py          # 标签 / 保存视图 / 重复文件接口（23 条，独立临时库）
node tools\verify_features_ui.mjs       # 三块功能的界面与交互：标签 chip / 存视图 / 重复组（CDP）
py -3 tools\verify_extras.py            # 双链 / TOTP / 快速捕获接口（28 条，独立临时库）
node tools\verify_extras_ui.mjs         # 双链渲染 / 动态码列 / 捕获浮层（12 条，CDP）
py -3 tools\capture_ui.py     # Chrome headless 真实界面截图 → docs\screenshots\
```

> `verify_notes.py` 使用独立临时数据目录（`ONLYONE_DATA_DIR`），不会读写 `data\onlyone.db`。
> `verify_m8.py` 目前仍会在「写请求 <10s」一条失败：强制重建期间写请求实测阻塞 12–19 秒（G-20），
> 其余 8 条断言通过。属产品侧提交粒度问题，不是索引维护引入的。
