# OnlyOne 个人工作台

单机、单人、离线的本地工作台。把散落在本机目录、OneNote、企微文档和脑子里的东西收进一个入口：**文件能全文检索、笔记能写能链、业务记录能归类、账号密码能加密保管**。

- **纯本地**：全部数据存在本机的一个数据库文件里，无账号、无云端、无网络依赖
- **文件夹交付**：整个程序目录拷到任意 Windows 机器即可离线运行，不需要安装
- **统一检索**：文件正文、笔记、项目、运维记录、链接一次搜完

## 功能总览

左侧导航分「知识 / 业务 / 系统」三组，共八个页面：

| 页面 | 作用 |
|---|---|
| **概览** | 落地页。最近改动、待跟进的运维问题、最近笔记、系统状态一屏看完 |
| **全局搜索** | 跨文件 / 笔记 / 业务记录检索，字面、语义、标签三种命中方式并存 |
| **记事本** | 三级结构富文本笔记，支持双链、表格、图片与 OneNote 导入 |
| **项目事项** | 以项目为单位汇总企微链接、运维记录与关联文件 |
| **运维记录** | 问题登记与跟踪，按类型、公司、状态、时间筛选，超期自动标黄 |
| **企微链接** | 企微在线文档链接集中登记 |
| **凭据库** | 账号密码本地加密保管，支持两步验证动态码 |
| **索引目录** | 本机目录扫描入库，附重复文件检测与体积统计 |

除页面外还有四项横切能力：**快速捕获**（全局热键随手记）、**标签与保存视图**、**只读预览**（文档内容与内嵌图片）、**数据导入与备份**。

## 概览

打开程序默认落在这里，一屏看完最近在动什么、有什么等着处理。

- 四个区块**全部只读**：最近改动（按修改时间倒序 8 条）、待跟进运维（未关闭的按挂起天数升序）、最近笔记（不含私密页）、系统状态（库体积 / 上次备份 / 监听目录 / 扫描状态）
- 点最近改动会跳到搜索结果并直接打开预览，搜索框里预填该文件名，关掉预览后仍停在结果列表
- 待跟进的运维记录点一下就弹编辑窗，不需要先去运维页再找
- 进去拉一次，可手动刷新；切回窗口且距上次超过 30 秒时静默重拉。扫描进行中只更新状态文字，不重拉整页
- 某个区块查询失败只让该块降级显示，不影响其他三块

## 全局搜索

- **字面检索**：Word / Excel / PPT / PDF / 文本 / 图片文件名与正文全覆盖，短词同样能命中
- **扫描件 OCR**：图片与没有文本层的 PDF，走本机离线识别，零云端依赖
- **语义检索**：搜「宕机」也能找到内容写着「服务不可用」的记录，结果单列一组
- **结果分组**：字面命中与语义相近分开呈现，可按业务类型过滤
- **标签栏**：搜索框下方列出所有用过的标签及使用次数，点一下即按标签过滤，也能和关键词组合使用
- **外部索引插件**：预留了可插拔接口，默认关闭；配好外部 CLI 才启用，结果独立成组
- **不静默截断**：单文件正文最多索引 200 万字；超宽表格（列数过多）的剩余列会转成文本行保留，不会整列丢失

## 只读预览

预览文档内容而不打开原程序，也不改动原文件。

- 正文默认显示 80 行、表格默认 31 行（表头固定），宽表可「放大查看」到 92vw 弹窗并分批加载
- 抽屉宽度可拖拽，标题栏可一键最大化
- **内嵌图片可见**：Word / PPT / Excel 里的图片收在文末折叠区，单击看大图、可上一张下一张、可在「适应窗口 / 原始尺寸」间切换
- **原位显示**：独占一段的图在原文位置居中出大图，夹在句子中的出行内小图，表格单元格里的出小图；滚动到才加载
- EMF / WMF 矢量图自动转成位图，流程图文字仍清晰；`.wdp` / `.svg` 等 WPS 私有格式不可预览，直接不列出
- **Word 里内嵌的 Excel 也能读**：直接嵌入的表格、OLE 对象、老式对象包都会抽出正文与表格，不需要先把表拆出来

## 记事本

三级结构「笔记本 → 分区 → 页面」，编辑器支持粗体、斜体、标题、列表、代码块、图片、表格。

- **布局**：笔记本下拉与分区页签固定在顶部（页签放不下时收进「⋯」），左侧页面列表、右侧编辑器，两栏各自独立滚动
- **拖拽排序**：分区页签可拖动调序；页面可在分区内排序，也可直接拖到另一个分区页签上跨分区移动
- **双链**：正文写 `[[页面标题]]` 即成为可点链接，编辑器下方显示「本页引用 / 反向链接」，找不到目标页时标「待建」
- **表格**：插入 3×3、增删行列、合并拆分单元格、删整表；行高可选紧凑 / 标准 / 宽松 / 自定义，列宽可直接拖拽，宽高随文档一起保存
- **粘贴即用**：`Ctrl+V` 可贴截图，也可从 Excel / 网页直接粘贴成表格
- **自动保存**：改动后 1 秒防抖落盘；切走页签时若还有未保存的改动，会先保存再离开，回来时仍停在原来的分区与页面
- **私密页**：单页可设「不参与检索」，不进入全文索引、语义检索与全局搜索
- 公开页面的正文自动进入全局检索，搜索结果里带「在记事本中打开」，一键跳到对应页面
- 顶部「更多 ▾」集中了导入、导出与备份（详见「数据导入与备份」）

## 项目事项

把同一个项目的资料收在一个工作台里。

- 左侧项目列表，可搜索，可按「进行中 / 已归档」过滤
- 右侧三个页签：**企微链接 / 运维记录 / 关联文件**，页签标题带数量徽标
- 在项目内新增的链接与运维记录，归属项目自动锁定为当前项目，不必再选一次
- 三个页签都是统一表格：新增、编辑、批量删除、复制为 TSV；双击行直接编辑
- 记事本不在此页出现。早先由项目页新建的页面仍保留在记事本「项目笔记」下按项目名命名的分区里

## 运维记录

登记问题从发生到处置的完整链路。

- **字段**：发生时间 / 类型 / 系统 / 提出人 / 公司 / 现象 / 根因 / 处置 / 状态 / 耗时 / 归属项目 / 备注
- **类型**固定五档：BUG / 优化 / 新需求 / 业务方案 / 流程效率
- **现象、根因、处置、备注为富文本**：可加粗、斜体、列表，`Ctrl+V` 直接贴截图（超过 5 MiB 自动压缩）；其余字段为纯文本
- 提出人、公司、类型都会进入全文检索，搜「流程效率」能直接筛出这批记录
- 列表「现象」列显示纯文本，带图时附 `〔N 图〕` 标记
- **筛选**：关键字全文、发生时间区间（可只填一端）、类型、公司、状态、项目，六者可叠加；顶部显示「筛选后 N / 共 M」，切走页签再回来筛选条件仍在
- **超期标黄**：未关闭且距发生时间超过 7 天，整行浅黄加左侧警示条，表格上方有图例说明
- 从全局搜索可一键「在运维记录中打开」，直接弹出该条编辑窗

## 企微链接

登记企微在线文档链接，便于集中找到入口。

- 记录标题、URL、备注，可归属到项目
- 只登记链接，不抓取也不读取文档内容
- 双击行即打开编辑窗，支持批量删除与复制为 TSV

## 凭据库

账号密码保存在本机，不上传、不联网。

- 用 Windows DPAPI 加密，绑定当前 Windows 账户，**无需主口令**
- 列表里账号、链接、备注常显，**密码默认掩码**；点该行密码列的眼睛图标才展开，刷新或离开页面立即恢复
- 编辑弹窗的密码框不回填明文，留空即「不修改」
- **动态码**：填了 Base32 密钥即可显示 6 位两步验证码，每 30 秒刷新，点击复制
- 密码与动态码密钥**都不进全文索引**，搜不到
- 支持加密导出：口令加密后只含密文，导入时用当前账户重新加密，**换机也能恢复**

## 索引目录

把本机目录纳进来，成为可检索的内容源。

- 添加任意本机目录（含爱数同步盘等挂载路径），扫描后建立全文索引
- 扫描在后台进行，界面显示进度，不阻塞其他操作；系统目录自动跳过
- **重复文件检测**：按文件内容比对分组，给出组数、冗余文件数、可释放空间；展开每组列出完整路径，提供「定位」与「复制路径」。**只报告不删除**，删不删由用户决定
- 显示索引库体积，便于判断是否需要维护

## 快速捕获

任何界面下按 `Ctrl+Alt+Space`，弹出一个小窗直接记一条。

- 弹的是独立的 **620×272 无边框置顶小窗**，主窗口完全不参与——不隐藏、不最小化、不还原
- 可记运维记录或笔记；`Ctrl+Enter` 保存，`Esc` 关闭，保存后焦点还给原来的窗口
- 笔记的落点可指定分区，**选一次即记住**，之后沿用
- 热键可改；未装依赖、组合被占用或主动关闭时静默降级，不影响启动，侧栏底部会显示「热键不可用」

## 标签与保存视图

**标签**：文件、笔记、项目、运维记录、企微链接都能打标签。

- 单个标签 ≤20 字，每条最多 10 个，自动去重
- 列表最右固定「标签」列显示前两枚，多余的显示 `+N`
- 编辑弹窗顶部一次录入；搜索页有标签栏，可按标签过滤或与关键词组合

**保存视图**：筛选栏左侧的「视图」下拉可把当前筛选存下来。

- 存的是**筛选条件**而不是结果，打开时按当时的数据重算，不会看到过期内容
- 按页面归属，运维 / 链接 / 项目各自一套，支持改名与删除，最多 50 个

## 数据导入与备份

入口在记事本顶部「更多 ▾」。

- **导入 OneNote**：支持 `.mht`（可多选）或整个文件夹。一个 `.mht` 对应一个分区，分区名取文件名，导入到当前选中的笔记本；重复导入自动生成「MM (2)」，不会混进旧分区
- **导出**：本页 Markdown、本页 HTML + 图片 zip、当前分区、整个笔记本
- 桌面端导出走**系统另存为对话框**，保存后提示完整路径，不会出现点了没反应的情况
- **备份全库**：一键打包数据库与附件

## 界面

暖纸主题，左侧一级导航（208px），窗口收窄到 1280 以下时自动收成纯图标栏，把宽度让给内容。导航项配线条图标，当前页用橙色竖条定位而不铺底色。

完整配色与排版规范见 `docs/设计方案.md` §8。

## 能力边界

这些是已知限制，不是待修缺陷，先说清楚：

- **OCR 只适合清晰印刷体**，手写、艺术字体、强噪声图片效果有限；插图中的文字不经过 OCR 搜不到
- **图片本身不进全文索引**，索引的是文本与文件名
- **语义检索基于同义词与字符相似度**，不是神经网络嵌入；同义改写跨度过大时可能不命中
- **内嵌图原位显示是段落级近似**，浮动图片会被拉到所在段落，且只对 `.docx` 生效
- **`.wdp` / `.svg` / WPS 私有扩展名不可预览**，直接不列出
- **凭据加密绑定当前 Windows 账户**，库文件拷到别的账户或机器无法解密；同一账户下的其他程序仍可调用系统解密，请勿在不可信环境运行
- **重复文件只比对 50 MB 以内的文件**，更大的文件不算哈希，界面会如实标注未参与数量
- **OneNote 导入有损**：子页面缩进、手写墨迹、非图片附件会丢失，站内链接降级为纯文字；整本导出为单个 `.mht` 时节边界不存在，整本只能进一个分区
- **单实例运行**：已有一个 OnlyOne 在跑时，再次启动只会把它的窗口置前并退出（两个实例会重复扫描并抢写锁）
